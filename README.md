# ♟️Knightly


A modern chess platform built with the MERN stack, designed to provide an interactive and engaging experience for players. Knightly supports real-time gameplay, puzzles, and social features like playing with friends.

Features
♟️ Play chess with real-time moves
🤝 Play with friends (custom matches)
🧩 Generate puzzles from previous games
📜 Game history and move review system
📖 Chess lessons (learning module)
⚡ Fast and responsive UI
📦 Progressive Web App (PWA) support
🔄 CI/CD pipeline integration



🛠️ Tech Stack

Frontend

React.js
Bootstrap / Tailwind CSS

Backend

Node.js
Express.js

Database

MongoDB

Other Tools

Stockfish (Chess Engine)
GitHub Actions (CI/CD)
Nginx (Deployment)
